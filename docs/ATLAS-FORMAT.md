# 动作图集规范 / Atlas Format

「小小的她」的每一个动作都来自一张统一的**动作图集（atlas）**。想让桌宠换成你自己的形象，就需要一张符合本规范的 PNG。应用内导入（托盘菜单 / 陪伴面板「徽章装扮 → 我的形象」）会强制校验以下全部规则。

## 画布

| 项 | 值 |
| --- | --- |
| 尺寸 | **1536 × 2288 像素**（精确匹配，不接受其他尺寸） |
| 网格 | **8 列 × 11 行**，每格 **192 × 208 像素** |
| 色彩模式 | **RGBA**（透明背景） |
| 文件格式 | **PNG**（导入时会自动转存；原始文件请直接提供 PNG） |

## 行布局与每行动作

| 行 | 动作 ID | 含义 | 非空帧数 |
| --- | --- | --- | --- |
| 0 | `idle` | 待机呼吸 | 7（第 8 格留空） |
| 1 | `run-right` | 向右跑 | 8 |
| 2 | `run-left` | 向左跑 | 8 |
| 3 | `wave` | 挥手打招呼 | 4（第 5-8 格留空） |
| 4 | `jump` | 开心跳跃 | 5（第 6-8 格留空） |
| 5 | `fail` | 失落反应 | 8 |
| 6 | `waiting` | 等待陪伴 | 6（第 7-8 格留空） |
| 7 | `run` | 原地小跑 | 6（第 7-8 格留空） |
| 8 | `review` / `feed` | 认真查看 / 吃点心 | 6（第 7-8 格留空） |
| 9 | 视线格 | 注视方向 0°–157.5° | 8 |
| 10 | 视线格 | 注视方向 180°–337.5° | 8 |

- 每行内**从第 1 格开始按帧顺序排列**，动画按帧序循环播放。
- 行 9/10 的 16 个视线格按角度递增排列（每格 22.5°），用于眼神跟随鼠标方向。
- 一行内「应留空」的格子必须是**完全透明**（alpha = 0）；QA 会精确核对每行非空格数量。

## 绘制要求

1. **角色一致**：所有格子必须是同一个角色、同一比例、同一锚点（建议脚底对齐每格底部同一基线），否则动画会抖动。
2. **不要触碰格边**：任何格子的四条边上都不允许有不透明像素（角色贴着格边会被判定为裁切风险）。给角色四周留几个像素余量。
3. **透明背景**：整张图画布除角色外全部透明，不要画背景、阴影层或分隔线。
4. **帧数不能多也不能少**：上表「非空帧数」是硬校验——非空格数量不一致会导致导入 QA 失败。

## 校验与安装工具

仓库自带一套可复用的命令行工具（需要 Python 3）：

```bash
py -3 -m pip install -r requirements-assets.txt

# 结构 QA：逐格检查非空数量、格边裁切，并输出联系表 artifacts/action-atlas-qa.png
py -3 scripts/qa-action-atlas.py --project . --atlas 你的图集.png

# 尺寸/格式归一化
py -3 scripts/normalize-atlas.py --input 你的图集.png --output normalized.png
```

应用内导入（推荐）会自动完成同样的校验：

- 托盘菜单 →「更换形象…」
- 陪伴面板 →「徽章装扮」→「我的形象」→ 选择文件或拖入 PNG
- 命令行方式：`"小小的她.exe" --install-custom-atlas 图集.png`（`--reset-custom-atlas` 恢复默认）

## 当前限制

- 自定义图集只替换上表的主图集；比心 / 害羞 / 庆祝三组手势特写是独立的 PNG 覆盖层（`public/assets/actions/`），仍使用默认素材。
- 衣橱的 8 套配色覆盖层是针对默认角色预生成的，换上自定义形象后叠色效果可能不贴合。
- 导入的形象保存在本机 `%APPDATA%/小小的她/custom-pet/`，不会进入仓库或发布包。

## Roadmap
